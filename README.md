# German with Atish

A black, distraction-light German A1 study companion. The 21-day intensive route follows the supplied Netzwerk neu A1 Kursbuch (176 PDF pages). Printed page numbers are one lower than PDF page numbers. The supplied HTML is the book's download landing page, not a second textbook.

Each full lesson requires two teaching passes with two explained examples each, three drills, a reading question, guided writing, and a fresh blind answer before completion. Separate reading, writing, listening, textbook and grammar spaces remain accessible.

The schedule budgets 260 focused minutes a day, plus breaks. It is an intensive study target, not a promise of A1 proficiency. Book assignments and official publisher audio provide the main extended practice. Final practice results and spoken performance are reported separately from completed app lessons.

All examples, reading passages and exercises in this app are original. The textbook is opened from the user's own PDF; it is not bundled or re-hosted. Publisher media and Goethe practice tests open externally. Browser speech uses a device voice and is labelled as such. Speaking and open-ended writing use explicit self-checks, not automatic AI grading.

Progress, drafts, timer and reviews live in localStorage (`klein-german-v1`, preserved from the earlier version). Export and import support moving progress between browser origins. Selecting a PDF opens it on-device for the current tab only.

Buildless hosting: `dist/index.html`. Run `node tests/verify.cjs` for content and flow checks, then `python3 build-standalone.py` for the offline single-file version.
