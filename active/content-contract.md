# Content contract v2 (6-month A1 → A2 → B1)

Spec of record for all course content. Size rules per level are in `content/levels.json` (`rules`); the compiler enforces them. The plan is in `~/.claude/plans/gentle-herding-duckling.md`.

## Learner and voice
- Complete beginner with ADHD. English explanations, short sentences, one idea at a time.
- **Grammar is the priority.** Every lesson is built around one grammar point. Explain every grammar term in plain English *before* using it.
- **Teaching comes first, questions second.** Lessons are mainly explanation in ELI5 style (see the `eli5` skill): one big idea per card, a picture or diagram for it, few words, colour-coded sentence parts, tables built up step by step. **Card format v2.1:** every lesson has **at least 4 visual teaching cards** (a diagram, a table, a step-by-step build-up, colour-coded sentence parts) before any question.
- **Plain labels for the learner.** Never show internal names. Say "New sentence on your own" (not "blind"), "Practice" (not "skill day"), "Review" (not "recall" or "retrieval").
- **German check.** After a chapter is written, a separate pass checks only the German (spelling, endings, word order, natural phrasing) before the learner sees it.
- **Listening.** Real voices (Nicos Weg, Easy German) carry listening. Text-to-speech is only for slow drills.
- **Teach before you test (hard rule).** Every rule, form or ending that a drill, check, blind, retrieval, skill question **or hint** relies on must be taught in a card of this lesson or an earlier one: shown, explained and given an example. Fixed phrases used before their grammar is taught (e.g. *ich heiße* on day 1) are taught as whole chunks ("learn *ich heiße* as one piece; why it ends in -e comes in lesson 4"), and their questions test the chunk, never the rule. Hard or "strong" grammar (irregular forms, stem changes, case endings, word-order rules) gets its own card with a table and ≥3 examples before it is tested. Hints use plain words ("With ich, use the form heiße") and only point back at something already taught.
- Original content only. Use the textbooks for *order and scope*, and Lingolia / Deutsch für Dich / Anja / Easy German to understand a point, but never copy their sentences or exercises. Write your own.
- Characters: Mira, Ben, Leon, Anna (plus neutral extras such as Frau Weber, Herr Ali). Never use the learner's name.
- German text in Unicode NFC (ä ö ü ß as single characters). Use „…" or plain quotes consistently.

## Files
- `content/levels.json`: plan shape and size rules (Opus owns it).
- `content/resources.json`: media catalog, generated by `tools/fetch-resources.py`. Never edit it by hand.
- `content/{a1,a2,b1}/inventory.json`: what each book chapter covers, with page numbers.
- `content/{level}/chNN.json`: **one file per chapter** (the writer owns the whole file).
- `content/{level}/mocks.json`: end-of-level mock exams.

## SkillDay (one per learn day; uses only grammar and words taught up to that day)
```json
{
 "id": "a1-c04-d2", "level": "a1", "chapter": 4, "day": 2,
 "reading":   {"title": "...", "text": "rules.readingWords words", "glossary": [{"de": "...", "en": "..."}], "questions": [ <Question> ×10 ]},
 "listening": {"title": "...", "script": "a dialogue or monologue, read aloud by text-to-speech; label speakers 'Mira: …'", "questions": [ <Question> ×10 ]},
 "writing":   {"items": [ <Question> ×10 ],   // guided: complete / build / transform
               "free": {"prompt": "...", "minWords": 15, "model": "a model answer", "checks": [{"label": "uses den", "pattern": "\\bden\\b"}]}}
}
```
Reading and listening questions test understanding of *that* text (who / what / when / why / true-false as choice). They are answerable only from the text.

## Question (used everywhere)
```json
{"type": "choice", "prompt": "...", "options": ["...", "...", "..."], "answer": 0, "hint": "...", "explanation": "...", "grammar": true}
{"type": "build",  "prompt": "Build: I eat an apple.", "tokens": ["Apfel.", "Ich", "einen", "esse"], "answer": ["Ich", "esse", "einen", "Apfel."], "hint": "...", "explanation": "..."}
{"type": "type",   "prompt": "Ich esse ___ Apfel. (ein)", "answers": ["einen"], "hint": "...", "explanation": "..."}
```
- **`hint` is required** on every question: a nudge toward the rule, never the answer itself. The app shows it after 2 wrong tries and then unlocks "Show answer".
- **`explanation` is required**: one line on *why* the answer is right. It is shown after a correct answer or a reveal.
- `choice`: 2–4 options, and `answer` is a valid index. `build`: `tokens` is a permutation of `answer`. `type`: `answers` lists **every** acceptable variant (word order variants, ß/ss, with or without the full stop is handled by the app).
- `grammar: true` marks questions that test the grammar point (it counts toward `checkGrammar`).
- Answer checking ignores case, punctuation and extra spaces, so don't list variants that differ only in those.

## Mock (`mocks.json` = array with `mockDays` entries)
```json
{"id": "a1-mock-1", "level": "a1", "title": "...", "sections": [
  {"skill": "reading|listening|writing|grammar", "instructions": "...", "text": "... (reading) / script (listening)", "questions": [ <Question> ... ]}
]}
```
Goethe-style format, original content, grammar section always included. Each mock has ≥40 questions.

## IDs
`<level>-c<NN>-<NN>` for lessons, `<level>-c<NN>-d<N>` for skill days, `<level>-mock-<N>` for mocks. IDs never change once published (saved progress is keyed by them).

## Honesty
Lessons done ≠ spoken or exam proficiency. The app reports "practice mock passed", never "certified".
